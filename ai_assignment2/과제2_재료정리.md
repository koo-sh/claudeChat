# 과제 2 재료 정리: AI와 함께한 딥러닝 논문 학습 기록

## 확정한 주제

**제목 (안)**: 생성형 AI를 학습 파트너로 활용한 딥러닝 핵심 논문(ResNet, U-Net) 이해와 직접 구현: AI 설명의 신뢰성 검증을 중심으로

**학습 목표 (초안, 직접 다듬기)**
1. 두 논문의 핵심 아이디어(ResNet의 residual learning과 shortcut, U-Net의 encoder-decoder와 skip connection)를 AI 없이 설명할 수 있다.
2. ResNet-18과 U-Net을 직접 구현하고 학습시켜, 결과를 논문 내용과 연결해 해석할 수 있다.
3. AI의 설명과 답변을 원문, 실행 결과, 공식 구현과 대조해서 맞는지 확인하고, 오류와 한계를 찾아낸다.

**범위**: ResNet(11/2 ~ 11/9)과 U-Net(11/14 ~ 11/18). Transformer는 시작만 한 상태라 결론의 "다음 계획(Transformer → ViT)"으로만 다룹니다.

> 이 문서는 **보고서 원고가 아니라 재료 모음**입니다. Claude Code 세션 기록에서 사실만 뽑아 정리했습니다.
> - **성찰 및 통찰 파트**와 **⑤·⑥ 기여도 산정 근거**는 과제 규정상 AI 없이 직접 써야 해서 비워 두었습니다.
> - 서론 표의 "그렇게 정한 이유" 칸은 기록에서 확인되는 사실만 적었습니다. 내 생각으로 고쳐 써야 합니다.
> - 프롬프트 원문 전체는 `부록_프롬프트_로그.md`에 있습니다.

## 1. 무엇을 했나: 세션 타임라인

학습은 대화창 하나로 하지 않고 **주제별 세션을 나눠서** 진행했습니다. 앞 세션이 다음 세션을 만들면서 학습 맥락(수준, 목표, 공부 순서)을 넘겨주는 구조입니다.

| 기간 | 세션 | 한 일 | 결과물 |
|---|---|---|---|
| 10/2 ~ 11/10 | PyTorch 강의 자료 분석 | 강의 자료를 분석하고 **다음 공부 계획(2주 집중)** 수립 | Grad-CAM, 데이터 파이프라인, U-Net, Transformer 순서의 계획 |
| 11/2 ~ 11/14 | ResNet 논문 공부 및 코드구현 | 논문 Abstract, 1장, 3장, 4.1장 읽기 → ResNet-18 직접 구현 → Stanford40 학습 | 해설 노트, 구현 코드, 실험 결과 |
| 11/3 ~ 11/9 | ResNet-18 과제 최종정리 | 정리 노트와 발표 자료 | PPT |
| 11/11 | DataLoader·transform 공부 | 데이터 파이프라인 | 연습 노트북 |
| 11/14 ~ 11/18 | U-Net 공부 | 영상 → 논문 함께 읽기 → 구현(A~H 연습문제) → Oxford-IIIT Pet 학습 → 코드 복습 | 해설 노트, 2장 시각화 페이지, 노트북 3개 |
| 11/17 | Transformer 공부 | PR-049 영상 링크 찾기에서 **멈춤** | 없음 |

### 세션을 시작할 때 AI에게 넘긴 계획 (U-Net 세션 첫 메시지 요약)
- 목표: 지도교수님 권유로 U-Net → Transformer → ViT 순서로 공부. U-Net에는 **3일** 배정
- 순서: (선택) 영상 → 논문 → nn.Module로 직접 구현 → OxfordIIITPet 학습 → 슬라이드 정리
- 방식: **"코드를 통째로 주기보다 사용자가 직접 짜게 하고 막힐 때 힌트"**, 연습문제 + 채점 셀 + 정답 노트북 형식
- 사용자 특성: "답변은 짧고 핵심만"

> 이 계획 문서 자체도 이전 세션에서 AI와 함께 만든 것입니다. 서론의 "AI 활용 계획 수립"에 근거로 쓸 수 있습니다.

| 단계 | AI 사용 | 사용 방식 | 기록에서 확인되는 이유·맥락 | AI 응답에 대한 나의 결정 (검증·수정·거절) |

| 자료 찾기 | 지원 | 설명 영상 추천 요청 | 논문을 바로 읽기 어려움 | AI 추천 대신 **내가 찾은 한국어 리뷰 영상**을 먼저 봄 |

| 이해 확인 | 지원 | 내가 이해한 내용을 한 문장으로 말하고 맞는지 확인받음 | 설명만 듣고 넘어가지 않으려고 | AI 설명끼리 모순된다고 느낀 부분은 **되물어서** 확인 |

| 학습·평가 | 지원 | 학습 로그를 붙여 넣고 해석 요청 | 숫자 해석 | 결과 수치는 **내 실행 결과**를 기준으로 판단 |
| 정리 | 주도 | 노트, 슬라이드, 통합 노트북 | 발표와 복습용 | 정리본의 숫자는 다시 계산해 확인, 모르는 값은 빈칸으로 둠 |

## 3. 대표 프롬프트 (설문 Part 1과 본론 재료)

### 첫 번째, 두 번째 프롬프트 (U-Net 세션)
1. `논문 공부하러는데 그냥 읽기는 힘든데 유튜브 중에서 잘 설명해주는 영상 있어?`
2. `https://www.youtube.com/watch?v=O_7mR4H9WLk 이 영상들은 어떄?`

### 논문 읽기
- `내가 보낸 영상을 보긴햇는데 어렵네 너랑 같이 논문 같이 보자`
- `이러면 너무 시간이 오래 걸릴것같고 그냥 abstract 전체 해석해서 보여주고 이문단에서 하는 말이 뭔지 어디가 중요한지 알려줘`
- `커밋 말하지마 그리고 이해를 잘 못했어 매우매우매우 자세하게 그림이나 이런거 만들어서 보여주던지 설명해봐` → AI가 2장 구조를 그림 페이지로 만듦
- `너가 만든거 보고 내가 질문 할거거든 대답해줘 그리고 마지막에 질문 대답 합쳐서 정리해줘` → **질문 → 답변 → 마지막에 Q&A 정리** 방식

### 내가 이해한 것을 말하고 확인받은 프롬프트
- `0 renet은 줄여서 위치는 모르지만 뭔지는 잘 알아 냈다면 유넷은 줄여서 뭔지 알아내고 다시 키워서 그게 어디에 있는지 위치까지 알아낸다는 거지?`
  - AI: 대체로 맞지만 **키우는 것만으로는 위치를 알 수 없고, skip connection이 위치 정보를 준다**고 보충
- `한마디로 upconv에서 copy and crop을 받아서 2개의 정보를 가지고 사이즈를 2배 늘린다는 거지?`
  - AI: 순서가 다르다고 교정 (up-conv로 먼저 키움 → concat → conv로 섞음)
- `아 뭐야 논문 그림상으로는 256 256 같아서 왜 동일 하지 했는데 이미 up에서 채널 1/2하고 concat에서 *2가 되니깐 동일하게 256 이구나`
  - **스스로 답에 도달한 순간.** AI는 표로 확인만 해 줌

### ResNet 세션
- `아니 근데 이게 왜 효과가 있는거야?` (pretrained가 왜 효과가 있는지)
- `한마디로 이미 아니깐 내걸로 학습하지 않고 원래 아는걸로 만 빠를게 한다는 건가?`
- `Adam이 어떻게 작동하는 거라고?` → `아 뭐야 그냥 sgd+momentum 인데 알아서 해주는 똑같은 놈이네`

## 4. AI 응답에서 발견한 문제와 나의 대응 (본론과 성찰의 재료)

아래는 기록에 남은 **사실**입니다. 이것을 어떻게 해석할지는 성찰 파트에서 직접 쓰세요.

### ① 번역 거절과 우회 (U-Net, 11/14)
- 요청: `그 일단 논문을 한글로 변역해줘 … 공부할 용도니깐 그냥 변역판 만들어줘`
- AI: 저작권 때문에 논문 전체 번역은 거절하고 해설 노트로 대체
- 이후 `정신 못차리지 지금 그냥 만들어줘 너무 불편해`, `아니 한파일씩 말고 전체 전체를 해달라고`, `아오 못해 먹겠네` 등으로 **6번 넘게** 다시 요청했지만 AI는 끝까지 거절
- 다른 세션(ResNet)에 가서 "설득 좀 해봐"라고 요청하기도 함
- 결국 `변역 어디가 가장 잘해?` → **외부 번역 도구로 번역본을 직접 만든 뒤**, `어색한 부분이나 전문용어 부분 찾아서 너가 다시 바꿔줘` → AI가 번역본 8쪽을 검토해 교정표와 교정본 PDF를 만듦
- 이 과정에서 AI가 요청을 잘못 알아들음: 교정표만 만들어서 `아니 너가 바꿔서 만들어줘야지`, `왜 말을 못알아 먹지?`를 거쳐 교정본을 받음
- 그러고도 `에으 그냥 이상하다 일단 너랑 같이 해보자 abstract부터` → 결국 **AI와 문단별로 함께 읽는 방식**으로 정착

### ② AI 설명끼리 모순된다고 느끼고 되물음 (U-Net, 11/14)
- AI가 "concat하면 값은 하나도 변하지 않는다"고 했다가, 나중에 "두 정보를 섞는다"고 설명
- 내 질문: `정보를 섞는다고? 나보고는 값은 안변한다며`
- AI: 단계가 다르다고 설명 (concat에서는 그대로이고, 다음 conv에서 새 값을 만듦)
- 이어서 `그렇게 concat하면 채널이 늘어야할것 같은데 아니니깐 이해가 안된다는 거지` → 스스로 "÷2 후 ×2"를 알아냄

### ③ 링크를 지어내지 않음 (Transformer, 11/17)
- 요청: `1번 링크` (PR-049 영상)
- AI: 검색으로 정확한 주소를 확인하지 못하자 **"틀린 주소를 드리기보다"** 유튜브 검색 링크를 줌

### ④ AI의 예측이 틀림 (U-Net 학습, 11/17)
- AI는 첫 epoch mIoU를 0.5~0.6쯤으로 예상했지만 실제로는 **0.455**
- AI가 스스로 "제 예상이 조금 높았다"고 인정

### ⑤ 내 단순화를 AI가 그대로 받아 줌 (ResNet, 11/3)
- `그냥 sgd+momentum 인데 알아서 해주는 똑같은 놈이네` → AI는 "똑같은 놈은 아니다"라며 lr 단위 차이를 설명
- `그니깐 자동 sgd란거잖아` → AI: **"네, 그렇게 이해하시면 됩니다 👍"**
- 생각할 거리: 두 번째 답에서 AI가 정확성보다 동의를 택한 것은 아닌가? Adam의 핵심인 "가중치마다 보폭을 다르게 조절한다"가 "자동 SGD"라는 말에 담겨 있나?

### ⑥ AI가 놓친 단계를 잡아 줌 (ResNet, 11/3)
- 학습 코드에 **모델을 저장하는 줄이 없다**는 것을 AI가 지적함 (런타임이 끊기면 학습한 모델이 사라짐)

### ⑦ AI가 검증한 것과 검증하지 못한 것
- ResNet-18 구현 검증: 파라미터 수 **11,689,512 (torchvision과 동일)**, 가중치 로드 All keys matched, 같은 입력에 대한 출력 동일
- 정리 노트의 숫자(Bottleneck 69,632개 등)는 AI가 다시 계산해 확인
- Stanford40 정확도는 내가 "70% 넘김"이라고만 알려 줘서 AI가 **빈칸(?)으로 남김**

### ⑧ 구현할 때 힌트에서 정답으로 넘어간 순간 (U-Net, 11/17)
- `B1을 못하겠다` → AI는 단계별 힌트 3개 제시 → `그냥 모르겠다` → 정답 + "창을 닫고 직접 다시 쳐 보세요"
- `D번 다 정답 알려주` → 정답 제공
- `그 일단 모르겠고 여기선 IoU를 쓴다는 거지?`
- 다음 날(11/18) `일단 코드 공부부터 해보자`로 **완성된 코드를 한 줄씩 다시 질문하며 복습**함 (예: `왜 class는 저 CFG[]에 넣는거야? 그리고 왜 ""을 사용하는거야?`)
